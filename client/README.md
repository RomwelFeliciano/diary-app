# client

React frontend for the diary app (Create React App). See the repo root
[README](../README.md) for full setup instructions.

## Scripts (run from this folder, or via `npm run <script> -w client` from the root)

- `npm start` — start the dev server (http://localhost:3000)
- `npm run build` — production build to `build/`
- `npm test` — run tests

Requires `client/.env.local` with `REACT_APP_API_URL` pointing at the running
server (see `.env.example`).
